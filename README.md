Repo **de guía**: muestra el programa completo y qué le toca a cada integrante. El repo de entrega es otro; ahí cada una/o sube su propia parte.

- `main.c` – programa completo (rama `main`)
- `reservas.txt` – datos de prueba
- `DOCUMENTACION.md` – documentación del programa
- `GUIA_INTEGRANTES.md` – qué hace cada una/o, ramas y preguntas para el oral

Ramas: `ornella` (opciones 1 y 2), `denise` (opciones 3 y 4), `santiago` (opciones 5 y 6).
